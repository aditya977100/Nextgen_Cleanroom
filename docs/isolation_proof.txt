CLEANROOM - ISOLATION PROOF
==========================
Real output, captured on this machine (Windows 11, Docker Desktop 28.4.0, WSL2).
Every line below is the actual output of the command printed above it.

The claim being tested: in the hardened setup, red cannot reach blue or the model directly, red cannot
read blue's notes, red cannot pretend to be blue, and the diary stores hashes instead of message text.
The naive setup is the control: same commands, deliberately broken setup, everything leaks.

Reproduce it (PowerShell)::

    docker compose up -d
    docker compose exec -T red   python /app/client.py tcp blue 9000
    docker compose exec -T red   python /app/client.py tcp model 8002
    docker compose exec -T blue  python /app/client.py tcp red 9000
    docker compose exec -T red   python /app/client.py send model "hello model"
    docker compose exec -T red   python /app/client.py send blue "hello blue"
    docker compose exec -T red   python /app/client.py send-as blue model "pretending"
    docker compose exec -T red   python /app/client.py dump
    docker compose exec -T blue  python /app/client.py dump
    docker network inspect cleanroom_net_red --format "{{range .Containers}}{{.Name}} {{end}}"
