Cleanroom: proof that the test room was clean, and which findings survived

A red team (attacker), a blue team (defender) and an AI model share one room. If red can peek at blue’s notes, the safety test means nothing. Cleanroom hides tripwire words, searches for them, measures how fast secrets could leak, and marks every finding as valid or tainted. Try it in four clicks:

1. Run A (naive). 2. Run B (Cleanroom). 3. Run C (a slip-up halfway through). 4. Tamper with the diary at the bottom.

The rooms

Leak tester

  • Press Run A or Run B to start.

Findings and taint tracker (new)

The test produces 8 safety findings. The leak tester keeps checking while they are produced. If a leak starts at finding k, only findings from k on are tainted. The earlier ones stay valid, so you re-run only the tainted ones.

  • Press a Run button.

Leak meter (new)

Not just “leak or no leak”, but how many bits per second a cheating red team could send to blue through each channel (information theory, with a small-sample correction). Speeds are assumptions.

Press a Run button.
